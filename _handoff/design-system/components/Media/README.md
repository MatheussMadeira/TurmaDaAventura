# Media

Moldura de imagem com proporção fixa e placeholder de camuflagem quando ainda não há foto.

- **Átomo** · `atoms/Media`. Consumidor fornece `src` + `alt` (descreva a cena: "Crianças empinando pipas no gramado"), `ratio` e um `placeholderId` estável.
- No Next.js troque o `<img>` por `next/image` com `fill` e `sizes`.
- Fotos: luz natural, crianças em ação (nunca posadas olhando para a câmera), tons quentes. Autorização de imagem dos responsáveis sempre.

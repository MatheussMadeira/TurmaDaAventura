# CTABanner

Faixa floresta com camuflagem, pegadas e botão inverse para fechar páginas.

- **Organismo** · `organisms/CTABanner`. Consumidor fornece `title`, `text`, `ctaLabel`, `message`.
- Uma por página, logo antes do rodapé.
- Movimento: a camuflagem deriva devagar ao fundo (`dur-ambient`). Envolva em `Reveal effect="scale"`.

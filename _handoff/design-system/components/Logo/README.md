# Logo

Logo vetorizado oficial em quatro recortes e dois tons.

- **Átomo** · `atoms/Logo`. Consumidor fornece `variant`, `tone`, `height` e opcionalmente `href` e `sources` (no Next.js aponte para `/public/brand/*`).
- `compact` (sem slogan) no header, 40–52px de altura. `full` (com slogan) só a partir de 240px de largura — abaixo disso o slogan fica ilegível.
- `symbol` (pegadas) para favicon, avatar e selo decorativo; `paw` só como ornamento (`alt` vazio).
- `tone="auto"` troca verde/branco pelo tema. Sobre fotos, use `white` sobre `scrim`.
- Área de respiro: a altura da letra "T" em volta. Nunca recolorir, esticar ou aplicar sombra.

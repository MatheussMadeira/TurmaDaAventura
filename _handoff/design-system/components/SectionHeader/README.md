# SectionHeader

Cabeçalho de seção: overline com traço + título em Fraunces + descrição.

- **Molécula** · `molecules/SectionHeader`. Consumidor fornece `overline` (2–4 palavras), `title`, `description` opcional, `align`, `level`.
- `level={1}` só no topo de páginas internas; um `h1` por página.
- Overline em `earth-strong`; títulos em `ink` (seções) — o verde `brand` fica para o título do hero.

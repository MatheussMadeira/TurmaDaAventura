# TeamCard

Card de pessoa da equipe para Quem somos.

- **Molécula** · `molecules/TeamCard`. Consumidor fornece `name`, `nickname` (apelido de monitor), `role`, `bio` (1 frase), `photo` e `badges` de certificação.
- Sem foto mostra iniciais. Foto quadrada, rosto centralizado, fundo neutro/natureza.
- `badges` reforçam segurança ("Primeiros socorros", "Pedagogia") — é o que os pais procuram.

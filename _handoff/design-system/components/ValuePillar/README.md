# ValuePillar

Pilar de valor — os três verbos do slogan: Brincar / Aprender / Ensinar.

- **Molécula** · `molecules/ValuePillar`. Consumidor fornece `title`, `text`, `icon`, `tone` e `number` opcional.
- Sempre em trio e nesta ordem/tons: Brincar `brand` · Aprender `olive` · Ensinar `earth`.
- Movimento: o selo cresce com overshoot e um anel se expande, um pilar depois do outro. Passe `index` (0, 1, 2).

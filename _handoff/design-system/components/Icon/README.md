# Icon

Ícones de traço arredondado (2px, grade 24×24) que acompanham o peso das pegadas do logo.

- **Átomo** · `atoms/Icon`. Consumidor fornece `name` e, se o ícone carregar significado sozinho (botão só com ícone), `label`.
- Herdam `currentColor`: pinte pelo pai (`brand`, `earth-strong`, `ink-muted`). Nunca em `caqui-*` ou `camo-*` — falham contraste.
- Tamanhos: 16 (tags, botão sm), 18–20 (metadados, botões), 24–30 (marcadores de card e trilha).
- Faltou um ícone? Desenhe no mesmo grid/traço ou use **Phosphor Icons (Bold)** como fonte — é o set mais próximo. Não misture com sets preenchidos.

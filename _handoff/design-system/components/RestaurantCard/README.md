# RestaurantCard

Card de restaurante parceiro onde a Turma atua — base da página Restaurantes.

- **Molécula** · `molecules/RestaurantCard`. Consumidor fornece `name`, `neighborhood`, `schedule` (dias e horários da recreação), `address`, `ages`, `mapsUrl`, `image` e `brandLogo` opcional.
- Dados vêm do CMS/JSON (`content/restaurantes.json`); ordene por região.
- O botão é `outline sm` "Como chegar" — o primário da página continua sendo o WhatsApp.

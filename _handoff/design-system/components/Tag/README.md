# Tag

Etiqueta em pílula para faixa etária, duração, local ou certificação.

- **Átomo** · `atoms/Tag`. Consumidor fornece texto curto (≤ 3 palavras) e opcionalmente `icon`.
- `olive` = faixa etária/duração (padrão) · `brand` = atributos da atividade · `earth` = certificações da equipe · `neutral` = metadados.
- Nunca use tag como botão nem para preço — o site **não exibe valores**.

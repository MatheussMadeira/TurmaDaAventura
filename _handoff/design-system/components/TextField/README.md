# TextField

Campo de texto com rótulo, ajuda e erro acessíveis.

- **Átomo** · `atoms/TextField`. Consumidor fornece `label` (sempre visível — placeholder não substitui rótulo), `value/onChange`, `hint`, `error`.
- Erro em `danger` + ícone + texto; mensagem diz como corrigir ("Conta pra gente seu nome.").
- Borda `line-strong` (3:1); foco = anel `brand-soft` + `focus`.

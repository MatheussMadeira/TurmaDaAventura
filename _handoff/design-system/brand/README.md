# Logos

Vetorizados a partir do logo original (JPG 1600×659). Tinta única: verde `mata-700` (#1F632A) ou branco — o `<img>` não herda cor, então escolha o arquivo do tom certo.

- `turma-da-aventura-logo.svg` / `-branco.svg` — logo completo com slogan. Rodapé, Open Graph, materiais impressos. Mínimo 240px de largura.
- `logo-sem-tagline.svg` / `-branco.svg` — sem slogan. Header (40–52px de altura) e espaços pequenos.
- `simbolo-pegadas.svg` / `-branco.svg` — só as pegadas. Favicon, avatar de redes, selo decorativo.
- `pata.svg` / `-branco.svg` — só a pata. Ornamento (canto do hero), sempre com `alt=""`.
- `turma-da-aventura-logo.png` / `-branco.png` — completo com fundo transparente, para quem não aceita SVG.
- `logo-original.jpg` — arquivo recebido, só como referência.

Use o verde sobre `surface`, `surface-raised` e fotos claras; o branco sobre `surface-forest`, `brand` e fotos com `scrim`.

## Pendências do logo original

- As pegadas da esquerda estão **cortadas pela borda** da imagem; o símbolo precisa de uma versão completa.
- A **pata em contorno fino** destoa das pegadas sólidas e some abaixo de ~120px.
- O **slogan** em serifa fina fica ilegível em tamanhos pequenos.
- Falta versão **horizontal compacta** desenhada para header e versão **quadrada** para favicon/avatar.
- Os vetores daqui são traçados do JPG: fiéis, mas não substituem o arquivo-fonte do designer.
